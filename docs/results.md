这轮的价值是明确定位下一步：**在设计准入处拒绝未支持类型，并让必需控件的可访问名称依据原始需求，而非仅依据模型自己的设计。** 下一轮仍保留冻结边界与累计回归；先离线复现这两个反例，再按[累计计划](redesign.md#iterations)推进。单次更高 token 不证明改动导致成本增加，单次内部通过也不能估计稳定成功率。
