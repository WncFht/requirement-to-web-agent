## 老师原版验收恢复

`e41f419` 将默认输入恢复为教师 ZIP 的原始字节，pending 扩展独立保留在 `examples/registration-pending/`。`97f0bdb` 冻结验收标准，随后增加老师四条原测试与十条独立行为/数据库检查；完整运行结论以 [实验报告](experiments/2026-11-01-baseline-optimization.md) 和验收工件为准。

`58a2358` 在生成测试冻结前拒绝已复现的恒假 header 断言；`b9da664` 补充完整 UI 可见性谓词提示；`f775805` 将 input/tests 作为只读交互契约供给前端，避免精确角色/标签与老师测试脱节。各语义修改均有回退开关及决策记录。这些修复的局部测试通过不等于应用完整生成成功。

`edaa473` 扩展序列化相等断言准入；`7e1c65f` 明确 API 分配的叶子边界；`ba05649` 拒绝外部 radio 角色冲突，并修正 radio 存在性断言；`2f984c0` 明确交互重试的已接受状态基准。固定验收修正为契约 v2，旧版哈希和反例仍保留。原版运行与历史扩展输入性能观测分开记录，不提前给出稳定标签。
