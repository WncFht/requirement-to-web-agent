# 文档归属

| 内容                                   | 唯一维护位置      |
| -------------------------------------- | ----------------- |
| 用途、环境和最短入口                   | 根 `README.md`    |
| 持续工作边界                           | 根 `AGENTS.md`    |
| 当前组件、数据流和所有权               | `architecture.md` |
| 开发、检查、诊断、仓库与本地产物维护   | `development.md`  |
| 版本选择、ZIP 契约与网站操作           | `submission.md`   |
| 运行结果、比较条件、未知用量和历史恢复 | `results.md`      |
| 完整运行配置协议、记录字段和历史索引   | `runs.md`         |
| 由 run 推导的问题、方案与待验证效果    | `redesign.md`     |
| 代码/当前文档不能解释的长期取舍        | `.agents/notes/`  |

先迁入独有内容再合并删除页面，修复导航、链接及锚点。重构计划可以摘取必要运行片段解释问题，不重复维护完整成绩表、提交清单和测试文件目录。新运行及详细审阅材料放 gitignored 的 `work/`；历史结论保留版本和证据边界，不改写原件。
