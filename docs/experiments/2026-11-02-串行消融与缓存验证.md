每次生成预算1200秒。完整成功要求内部 typecheck、后端、UI、生成 E2E、构建及独立固定14条、生产启动后相同14条全部通过，无 skip/flaky。首次失败即停止该次后续阶段，其耗时与已返回 usage 仍计入。所有配置使用同一预置依赖快照，准备时间单列，流水线自身安装检查保留；这是相同暖依赖条件下的比较。

## 贡献拆分与速度结论

按组计算四组合主效应：单事件收窄的总 token 平均加性变化为−304,556，前缀排序为+224,466；3组穷举块 bootstrap 的探索性区间分别为[−914,495, +277,290]和[−113,791, +545,340]，均跨零。只统计成功调用或模型调用数，会漏掉前期失败与后期修复的成本。

两项开启相对关闭的完整尝试耗时平均增加165.4秒，探索性区间[−126.9, +476.3]秒。两组配置没有同组双方都成功的配对，无法估计成功输出的配对速度收益。仅第3组的 `10/11` 都成功：排序开启时 token 少21.7%、完整耗时少21.6%，但只有一个配对，不给出零宽置信区间，也不作可复现提速结论。

这些试验控制了本地模型运行重叠、源码、输入、断言和依赖条件；服务端负载、缓存路由和生成轨迹仍不可固定。失败含早期停止，较短耗时不代表更快交付。历史匹配创建调用输入减少73.4%的证据继续支持局部上下文减量；当前完整消融尚不能确定各项最终收益的精确排名。

## 缓存 V2：局部复用有效，完整收益未通过

12对 Stage11 请求使用相同字段和值、独立实验命名空间、每臂一次独立预热和交错顺序；全部响应重新通过原契约校验。仅排序变化也可能改变 tokenizer 边界，输入量分别为46,321和46,309 token。

| 回放指标，不含预热 |      V1 |      V2 |
| ------------------ | ------: | ------: |
| 输入缓存命中率     |   29.8% |   87.1% |
| 未命中输入 token   |  32,497 |   5,989 |
| 输出 token         |   1,354 |   1,467 |
| 外层请求累计耗时   | 20.69秒 | 21.57秒 |

局部未命中输入减少81.6%，请求耗时没有下降。原始26次 SDK 调用包含2次预热；请求身份、字段值、响应校验、usage及汇总均核对通过。外层计时包含调用与日志处理，SDK内层计时分别保留，不要求二者相等。

V2完整生成分别消耗1,749,451和181,480 token，758.5和172.0秒，均失败；全部失败成本1,930,931 token。全流程输入加权命中52.5%，原默认3次为51.9%；候选没有成功输出，无法建立成功应用的缓存或成本收益。第二次在 Stage10 失败，尚未执行 V2 的 Stage11/12，不能把低成本或低命中归因于 V2。

主实验唯一成功默认运行的命中率只有30.3%；某些失败运行超过50%。按编辑轮次拆分，默认第1次失败中后续修复消耗1,176,547 token，输入命中66.5%，首次编辑输入命中22.3%。重复修复使相似请求反复出现，命中率因此可能升高。字段及文件变化、首次请求和不同阶段的非共享输入仍会造成未命中；服务端缓存状态也不可控。目标应是减少有用交付的总成本与未命中输入，不能添加无用上下文追求50%。

## 失败定位与后续优先级

完整轨迹暴露的主要缺口发生在正确性和测试准入。后续应先修这些缺口，再登记新的固定提交验证；这批运行不修改冻结测试转绿。

- `b2-2-11/b3-2-01/b3-3-00`：注册、登录写入的 Cookie 与会话查询接受的名称或传输方式不一致。实际后端处理器的隔离调用确认，真实生产端使用的 Cookie 被查询端直接按未登录处理。单接口测试和生产 Cookie 名称观察没有覆盖接口组合。
- `b1-2-10`：测试只向数据库插入 Session，未给浏览器凭据，却要求已登录；`v2-fixed-1`：最后选择 Male，却断言保存 Female。冻结前需要核对动作、前置条件与断言的关系。
- `b1-4-01/b2-3-01`：错误提示的 UI 可见谓词与真实错误状态不符；`v2-fixed-2`：UI测试生成读取缺失初值 `search.highSpeedOnly`，Stage10抛出 KeyError。设计准入须覆盖状态与绑定完整性。
- `b2-4-00`：内部全部 GREEN，但固定验收7/14；两个同时出现的用户名节点使老师的精确文本定位报 strict-mode 冲突。外部测试定位语义需要进入设计/终验约束。
- `b1-3-11`：外部提交按钮关联的表单缺少匹配 HTML id，属于静态动作不可达线索，未追加浏览器复测；`b2-1-10`：Stage06提案结构三次不合格，早于两项优化。
