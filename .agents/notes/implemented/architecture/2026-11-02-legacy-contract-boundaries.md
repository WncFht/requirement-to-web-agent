# Agent Note: 设计边界保留外部交互契约

Status: implemented

legacy 在设计提案阶段核对叶子需求的数据库义务、可见性与外部交互契约，保持既有校验和真实验收。提前拒绝已知不一致可以避免在冻结后只靠实现修复；代价是这些检查覆盖有限表达形式，不能替代业务验收。

API 分配同时比较 missing 与 excess。导航到别的需求页面，不自动把该页的读取 API 分给当前叶子；写入时持有 ID/凭据也不等于读取数据库。程序不自动裁掉字段或修改共享 API 让提案过关。

交互提案失败后没有写入已接受状态，纠错必须相对原 existing_interactions 重提所需完整记录，不能针对 previous_response 返回增量。提示给出 source/event/action 的明确记录形状，不接受或转换旧式嵌套简写。预算、义务集合和合并规则保留。

input/tests 的原始 TypeScript 作为只读设计证据传入，不按旧文件编号筛选需求，不复制成自生成测试或替代原 gate。精确角色、标签和路由是外部交互契约；已知 radiogroup 不能以同名 select 取代，radio 必须有静态选项值和共享选择绑定。

可见性必须表达完整业务谓词。现有 IR 只比较单变量，合取条件应成为事件维护的派生 boolean，并在 fixture 中明确赋值。外部测试要求准确用户名时，非空 username fixture 需要 text/heading 消费该绑定，静态账户标题不能代替身份；该准入不推断派生条件实际值，对象身份等形式仍依赖浏览器验收。

这些规则不自动改写旧设计或冻结测试。外部测试的字面量识别可能漏掉其他表达式，模型也可能继续产生非法提案；有限校验失败时应保留证据并停止，不猜测修正。行为回归与反例保留在 `tests/`，历史现场证据入口见[结果摘要](../../../../docs/results.md#历史证据)。
