# Agent Note: 流水线与检查的计时边界

Status: implemented

计时采用独立追加日志和可跨子进程连接的父子 span；每次调用用单调时钟测 wall time，显式区分入口、流水线、阶段和模型/检查，代价是少量日志 I/O 与尚未覆盖的本地准备时间。

原模型 elapsed_seconds 只记录请求累计时间，不能代表整条流水线，尤其不能遗漏编译、浏览器检查、依赖安装、退避与失败重试。解析终端的 Completed in 无法可靠保留未完成尝试。选择独立 start/end 记录而非覆写单份阶段汇总，是为了让强制终止留下未闭合记录，并使续跑与成功尝试分别可核查。

父子耗时明确为包含关系；汇总保留各层，不把父子相加。SDK create 内部重试属于同一 model_request，外层显式退避另列；该边界不宣称把服务端计算与网络延迟分开。时间戳只用于定位，不用于跨进程 duration 相减。固定老师验收在入口之外，旧日志缺少检查测点，不能事后推断成实测。

记录只接受内部类别、标识符、状态、返回码与异常类型，不复制命令、请求、环境或异常正文。日志故障保留原操作结果并发固定警告；计时故障不应把失败 gate 变绿或掩盖原异常。ARC_DISABLE_TIMING=1 停用新增测量，保留原模型审计；trace 和测量日志不应使可信完成记录失效。退出或 SIGKILL 导致缺失 end 时，汇总保留未知，不记作零。

操作接口与度量含义归[开发指南](../../../../docs/development.md#流水线与检查耗时)。单元测试覆盖嵌套单调时钟、跨真实子进程父子关系、异常/超时/非零结果、回退、写入失败、原始模型审计关联及相同请求重试；汇总测试覆盖父子排除、失败与续跑、截断/重复/非法记录及压缩读取。新增计时不改变提示词、原检查命令或通过条件；首轮全新模型运行在错误 Cookie fixture 修复循环中主动中断，实测与真实浏览器正反对照归[计时验证](../../../../docs/experiments/timing-validation.json)；显式空 Cookie 名结构适配后的固定 14 条诊断通过不能代替失败的内部 E2E。完整模型生成和应用验收结果单独归实验报告，不把增加测点称为性能提升。
