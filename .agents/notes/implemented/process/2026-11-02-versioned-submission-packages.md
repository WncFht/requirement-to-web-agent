# Agent Note: 交付身份由提交与引擎共同确定

Status: implemented

打包只读取指定 Git 提交，原平台入口保存在包中，由薄入口固定 upstream/coding 并补默认模型名。本地 make 生成执行同一份包，避免版本名与实际代码不一致；代价是未提交改动必须先提交才能交付，两条路线的运行依赖需分别核对。

平台只保证 URL/Key，而客户端还需要 MODEL，因此包装器补模型名但不覆盖连接凭据，宿主 ARC_AGENT_ENGINE 不能改变已打包引擎。包外清单保留源码和 ZIP 哈希，平台 ZIP 与源码备份不能互换。目录发布独立于打包身份，见[目录适配](../bug-fix/2026-11-02-platform-output.md)；实际范围归[交付指南](../../../../docs/submission.md)。

legacy/candidate 旧标签已删除，恢复改用提交 SHA 或本地 tar；提交本体仍在共享 main 历史中。保留三个具名证据标签的方案没有采用：标签没有提供 SHA 之外的正确性或维护保证，历史证据不应被误解为当前受支持引擎。重写 main 历史也没有采用，因为会破坏已共享的证据链。代价是旧标签命令失效，历史源码需显式选 SHA；不重建 legacy 驱动或运行别名，打包器识别历史布局不等于当前入口支持它。版本表和恢复方法归[历史证据](../../../../docs/results.md#历史证据)。

旧包、SHA 身份及原成绩不改写，新目录和相邻 run.json 记录每次来源。测试覆盖双引擎隔离、历史布局、未提交文件排除、确定性、环境传递、原入口字节、拒绝覆盖和路径安全。实际 ZIP 仍需阻断模型启动或假服务完整模拟；静态来源和重新包装不能作为真实任务成功证明。
