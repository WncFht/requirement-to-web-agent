# Agent Note: 交付身份由提交与引擎共同确定

Status: implemented

打包直接读取指定 Git 提交的运行源码并固定引擎，原 main.py 字节保存在包中，由薄入口补默认模型名；本地运行执行同一份包。这样让版本名、实际源码和交付行为可核对，代价是新增适配层，未提交修改必须先提交才能交付。

不压缩整个目录，避免混入模型配置、生成应用或独立验收；不改写历史入口，保留原源码哈希。旧 legacy 客户端还要求 MODEL，而平台只保证 URL/Key，所以包装器只补模型名，不覆盖地址和凭据。逐文件与 ZIP 哈希保存在外部清单，引擎不受宿主 ARC_AGENT_ENGINE 改变。

当前源码只支持整理后的 legacy 布局，旧 root 编号入口识别局限在打包器。新 ZIP 不再需要重复的 engine.json；指定引擎由薄入口固定，清单供核对。历史 ZIP 原件与标签保持不变，新的包装行为不能继承历史应用验证作为平台认证。

本地生成用新输出与相邻身份清单，退出删除临时源码，失败产物保留。可信续跑继续走源码入口，不跨提交或引擎混用记录。重复内容可复用同一个 ZIP，目标内容不同则拒绝覆盖。

测试覆盖旧/新目录、未提交文件隔离、确定性、原入口身份、引擎固定、凭据环境传递、拒绝覆盖和不安全路径。完整包仍需本地模拟或平台验证，静态哈希检查不证明业务正确。当前契约见[打包范围](../../../../docs/packaging.md)，命令见[提交指南](../../../../docs/submission.md)。
