# Agent Note: 父子计时与未知用量

Status: implemented

计时使用独立追加日志和跨子进程父子 span，每次以单调时钟测 wall time；入口、流水线、阶段和模型/检查分别记录。代价是少量日志 I/O，准备时间不一定全在这些边界内。

模型请求累计耗时无法代表包含安装、浏览器、编译、退避和失败重试的完整运行。保留 start/end 使强制终止留下未闭合记录，续跑与不同尝试分开核对。父子耗时有包含关系，汇总不能相加；时间戳仅定位，不用跨进程时间戳相减计算 duration。SDK 内部重试属于同一请求，外层退避单列，不声称分开网络和服务端计算。

只记录内部类别、标识符、状态、返回码与异常类型，不复制环境、命令、请求或异常正文。日志失败保留原操作结果并发固定警告，不能掩盖原异常或把 gate 变绿。ARC_DISABLE_TIMING 停用新增测量，原始模型审计保留；日志不能使完成指纹失效。

缺失 end 或 SDK usage 保持未知，不记零成本。只按 SDK 返回 usage 汇总，HTTP 镜像事件不重复计数，不推算供应商账单。旧日志缺测点不能补成实测。嵌套、真实子进程、异常/超时、失败续跑、截断重复与写入故障均有回归；当前上游使用自身日志与 SDK 耗时，旧 span 格式只适用于保留的支持工具或历史记录，不能给新上游补成全流程计时；操作归[开发指南](../../../../docs/development.md#诊断与验收)。
