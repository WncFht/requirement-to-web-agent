baseline 中共享 gender 绑定被错误用于每个 radio 的 value，导致 UI 阶段通过、交互接入后最终回归失败。第一轮保留教师 13e78ef 的十三阶段，按原结构分别检查固定选项 value 与 checked 状态；在设计转换前要求引用绑定有初值、radio 有明确选项值。依据与原始轨迹见[重构计划](../../../../docs/redesign.md#motivation)。

测试只有在现有阶段准入后才能冻结。后端保留原行为 RED 条件，增加两类已有失败依据的 JSON.stringify 矛盾检测；E2E 保留已有结构/编译/行为准入，拒绝写展示 fixture。这些窄静态规则可能漏检其他语法，不构成一般测试正确性证明；本轮不额外调用模型审阅。

生成套件的 SHA-256 写入 .arc/frozen_tests.json，并保留进程内副本；FileWorkspace 即使被扩大 writable 也拒绝写冻结测试，每轮 gate 前后检查所有封存套件。失败任务会连同新套件字节与哈希归档，再按教师机制恢复任务前现场；此前接受的套件仍冻结。直接修改或删除已封存套件、伪造本次进程的 receipt 都必须失败。记录不能证明跨进程可信续跑，也不能把执行 npm 的环境变成恶意代码沙箱。

另一选择是整体替换教师最新十一阶段；原样候选的离线门禁尚未通过，因此先在可验证基座修复已知错误。另一选择是允许实现者改测试完成任务，会丢失最终回归的独立约束，拒绝采用。发现错误冻结测试时保留当前失败，下一轮修改生成器，从新目录重来。

教师原 119 项测试保持原字节，新增回归在 tests/compiler 独立执行，覆盖语义反例、篡改和失败归档；完整生成效果另归[结果摘要](../../../../docs/results.md)。本决定部分更新[原生检查与独立验收边界](2026-11-02-frozen-tests-and-oracle.md)：coding 与固定验收仍独立，compiler 新增本轮明确列出的检查，不整套搬入 legacy。

第一轮实际运行接受了 type=radio 并漏出控件断言，且模型生成标签与测试期望共同偏离原始名称。后续将 radio 别名规范化，并对未知类型及 UI 父链失败关闭；明确字段列表和引号名称从需求原文提取，进入设计准入与精确名称浏览器断言。自然语言解析刻意限于可核对的窄语法，未识别部分仍有覆盖缺口。相比直接扩大固定验收定位器，这个选择保留需求到实现的约束。阶段回放只改变隔离实验目录，冻结检查继续有效，不把旧 GREEN 或事后修正迁入原运行成绩。
