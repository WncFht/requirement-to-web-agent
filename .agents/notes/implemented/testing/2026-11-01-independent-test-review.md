# Agent Note: 冻结前独立检查断言矛盾

Status: implemented

生成后端测试在静态准入之后、冻结之前增加一次独立模型调用，检查断言和 helper 调用是否互相矛盾。第五次失败把要求不含 password_hash 键的响应保密 helper 用在主动构造的含该键数据库对象上，说明两条静态模式不足。快速模式独立诊断调用在 2.7 秒识别该反例；完整调用审计保留在独立 probe 工件。

审阅不修改文件，不以当前 501 stub 失败判断不可满足，也不放松业务断言。明确矛盾或无效 verdict 均不准入，让原测试生成器在原有预算内纠正；相同候选源码复用已接受审阅结果。TypeScript、行为 RED、冻结后 GREEN、回归与独立老师验收仍全部执行。ARC_LEGACY_TEST_REVIEW=1 恢复不审阅的旧路径。

该检查增加模型成本，且同一模型的第二次调用仍可能误判或漏检，不是形式证明或独立模型集成。单元测试覆盖拒绝、无效 verdict、回退及原件不改写。全流程成功率、总成本和是否避免重复修复必须另以实际运行衡量，不能从一次反例诊断推出收益。
