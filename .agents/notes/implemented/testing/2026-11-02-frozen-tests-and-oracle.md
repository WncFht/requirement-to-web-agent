# Agent Note: 冻结测试与独立验收保持不同职责

Status: implemented

测试冻结前检查可执行性与已知矛盾，冻结后实现只能修改业务源码；独立验收使用预先固定的教师和额外断言。三者分别减少不可满足测试、约束实现、验证业务，不互相替代，也不承诺形式化正确性。

后端静态准入拒绝直接返回 JSON.stringify(value ?? {}) 却要求其逻辑否定为真，以及序列化结果等于非 JSON 字面量等窄模式。它不解析任意 JavaScript，复杂同名/影子绑定可能需要写成更明确的断言。独立模型审阅只报告具体内部矛盾，不改源码，不用当前 stub 失败认定矛盾；无效 verdict 与明确矛盾都拒绝准入。该额外调用增加成本，同一模型可能误判或漏检，不算独立模型证明。

E2E 禁止使用仅供 UI 存在性检查的 **ARC_UI_FIXTURE**，保留随机 loopback URL、类型与真实断言式 RED。动作超时、服务/浏览器/运行时错误不能冒充 RED；动作前要求同一 locator 的可见性及必要 enabled 断言。CheckFailure 携带原报告，结构化反馈与清晰动作顺序只改善诊断，不放宽门禁。标识符检查连同名注释也拒绝，不能识别所有绕过。

UI 检查同时要求 accessible name 与精确 getByLabel 指向实际控件，保留 password 类型及原生关联；装饰星号隐藏不保证精确标签匹配。radiogroup 必须在实际 DOM 中包含后代 radio，允许额外布局层；分别核对选项 value 和共享选择对应的 checked。严格唯一性失败不能用取第一个匹配掩盖。

会话证据来自临时副本中原后端断言的真实 Set-Cookie，再由 Chromium 保存；原源代码、断言和生产数据库不动。只保存名称、计数和源码身份，不记录凭据。空名称与无观察结果不同；正向预置会话需要已观察名称，未知证据时通过真实注册/登录建立会话。字面量与动态 fixture 均在冻结前检查，负向未知会话不受正向名称约束。多个 Cookie 至少一个匹配不证明凭据与数据库关系，英文标题和 producer 覆盖均有限制。

只读 GET mount 处理器增加隔离 503/拒绝 promise 探针，预期读取失败应清除旧身份、更新状态并返回，不能清理后重抛。探针只替换 context.api，不发网络请求、不吞全局异常；未执行 API 的分支标 NOT_EXERCISED，不计已覆盖，也不拒绝有条件的合法路径。真实 F04 浏览器检查仍执行。

固定验收保留教师原文件及输入哈希，四条教师与十条额外断言在隔离数据库上运行，生产再执行一次。适配只转换字段位置与实际 Cookie/存储编码，未知必填项拒绝猜测，识别失败不能跳过。F04 使用查询失败后的身份/数据不变量，不额外要求教师未规定的入口链接；历史断言修正有独立版本，不能把前后改变的验收当作受控性能比较。

真实正负控制、拒绝 skip/flaky/空套件、动作与准入反例有回归；旧失败运行不改写。当前 14 条不评估视觉相似度，生成测试也可能覆盖不足。历史人工补写、诊断后通过和中断均不能回填为完整自动成功，证据见[结果摘要](../../../../docs/results.md)。
