# Agent Note: 两条路线的原生检查与独立验收分开

Status: implemented

教师路线保留上游原生测试与门禁，coding 保留原候选的 RED、冻结测试和全回归，独立验收使用预先固定的教师与额外断言。三者不互相替代，不因新路线而把旧成功记录移植过来。

coding 冻结前拒绝部分已知动作/断言矛盾、fixture 注入和测试绕过，冻结后错误测试以 INVALID_TEST 结束，不能修改期望修绿。实际 typecheck、后端、UI、E2E 和构建必须全部通过，无空套件、skip 或 flaky。上下文、预算和编辑范围变化也不能放松这些规则。

旧 legacy 曾增加恒假 header 准入、独立模型审阅、精确标签、单选包含关系、Cookie 实测、只读失败探针等窄检查。这些规则有反例依据，也各有误判、标题/语法覆盖及成本限制；它们不能当作一般正确性证明。新默认按用户要求照搬上游，没有把整套旧补丁加入快照。旧决策与失败证据由历史提交和本地归档保存；support 仅保留候选/评估需要的检查依赖，不代表旧十三阶段仍被执行。

Cookie 评估以临时副本的真实响应和 Chromium 交付为依据，空名称不同于未观察结果；名称匹配仍不能证明数据库凭据关系。只保存名称、计数和身份，不记录凭据，未知必填项拒绝猜测。适配器只转换真实 schema/会话位置与已证明的编码，不能改断言或跳过不识别场景。

固定验收保留根教师输入原字节、四条教师和十条独立断言，开发及生产各一次，生成前后的身份可核对。F04 以读取失败后身份/数据不变量为准，不追加教师未要求的入口链接；历史断言修正不能冒充从头未变的受控比较。

上游 119 项原单测、coding 正负控制、模型模拟和原验收范围仍分别记录。上游已有一轮最终回归失败的真实生成，当前 14 条仍不评估视觉相似度，人工补写、后续诊断与中断都不能回填自动成功。结果归[结果摘要](../../../../docs/results.md)。
