# Agent Note: 精确标签定位进入页面验收

Status: implemented

页面存在性测试现在对可见、有标签的编辑控件同时验证 accessible name 与 getByLabel(label,{exact:true}) 指向同一个 data-testid。前者在隐藏必填星号时可能通过，而老师真正使用的精确标签匹配仍失败；原版候选因此有六条场景卡在填写密码。新断言在 Stage 10 和后续 UI 回归执行，保留原类型、值、可见性与全部行为验收。

页面与事件修复提示要求有装饰文本时在实际控件上设置精确 aria-label，保留原生 label 关联和 password 类型。ARC_LEGACY_LABEL_LOCATORS=1 恢复原提示/断言范围，老师原测试与固定验收从不改写。

同页同名控件可能触发严格唯一性错误；这与当前外部测试需要唯一定位相符，不能通过选第一个匹配掩盖。单元测试覆盖定位到实际控件及回退；真实浏览器反例和完整运行证据归实验报告，不把源码字符串检查视为应用通过。
