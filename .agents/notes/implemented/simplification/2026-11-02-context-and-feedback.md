# Agent Note: 有限创建上下文与完整最终修复

Status: implemented

legacy 非终验事件创建使用目标事件的较小上下文，需求最终修复保留全量页面、事件与冻结测试；稳定内容优先排序，结构化反馈保留独有诊断。减少重复输入有局部依据，完整成功率和耗时收益仍未建立。

基本收窄保留接线文件与相关页面，将 API/契约限制到目标事件。进一步的单事件路径保留该事件全部触发器、源元素、完整 P/Q、场景和所有前端绑定，因为自然语言动作没有可靠读集合，不能按写权限猜测读取依赖。创建只授权新 handler，跨文件修复由最终全量调用承担；类型错误落在未供给文件时可能耗尽修复预算，这是范围收窄的代价。

稳定键序与文件排序保持全部字段、值和编辑权限，易变事件注册表放后；它改变模型输入顺序，不承诺生成语义完全不受影响。保留 ARC_EVENT_CONTEXT、ARC_CACHE_PREFIX 作为有效调参，ARC_FULL_CONTEXT 用于全量诊断。未通过完整验证的缓存 V2 已从当前实现移除，历史源码由标签保留。

反馈以 CheckFailure 传递原报告，首轮字典作为一条完整反馈，不展开成键名。只有 output 解码后与其他全部字段在类型和值上严格相等，才删除重复副本；独有输出保留，源对象不变。ANSI 清理和截断不能证明全部诊断完备，原始审计日志继续保留，ARC_FULL_FEEDBACK 可查看原格式。

不按 local 动作或字段写集合直接合成事件：自然语言描述不提供有限赋值表达式，不能可靠区分输入镜像、转换、初始化或条件分支。未来若引入 DSL，需先证明模式前提和正负例覆盖，不能提前计算尚未节省的调用。

历史匹配创建输入确有减量，缓存局部回放也有命中改善；完整消融样本包含失败且效应区间跨零，V2 两次完整生成均失败。局部字符减少、缓存命中或成功样例不能替代端到端交付成本，详见[结果摘要](../../../../docs/results.md)。
