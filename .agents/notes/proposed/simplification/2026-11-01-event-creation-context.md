# Agent Note: 单事件创建上下文进一步收窄

Status: proposed

稳定运行 Stage 12 消耗约 64% 总 token。18 次非终验创建调用每次仍带全部事件、触发器、页面树、页面源码与外部参考测试，单次输入约 25k token；局部文本/checkbox 处理也承担同样成本。

ARC_EVENT_CONTEXT=1 试验只向非终验单事件创建供给当前事件、完整 P/Q、所有共享触发器、触发源元素、全部可用前端绑定、需求文本/场景、相关 API 和页面路由。保留全部绑定是因为自然语言动作没有可靠读集合，不能只按 write 裁剪。创建阶段只授权新 handler，页面/已有 handler 修复仍由原全量终验调用完成。默认 0 保持稳定版本，ARC_FULL_CONTEXT=1 仍可强制原全量路径；所有 typecheck、浏览器回归、外部固定验收和构建保留。

风险是缺少页面源码后模型对接线的理解变差，可能把成本转移到终验修复。验收要求同一老师输入/固定验收下对照 token、调用、失败与重试，配合相同已录请求的上下文字符重放；不得把字符当 token 或单次不同生成轨迹当因果效应。完整结果未取得前维持 proposed，默认不启用。
