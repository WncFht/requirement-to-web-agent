# Agent Note: 单事件创建上下文进一步收窄

Status: proposed

稳定运行 Stage 12 消耗约 64% 总 token。18 次非终验创建调用每次仍带全部事件、触发器、页面树、页面源码与外部参考测试，单次输入约 25k token；局部文本/checkbox 处理也承担同样成本。

ARC_EVENT_CONTEXT=1 试验只向非终验单事件创建供给当前事件、完整 P/Q、所有共享触发器、触发源元素、全部可用前端绑定、需求文本/场景、相关 API 和页面路由。保留全部绑定是因为自然语言动作没有可靠读集合，不能只按 write 裁剪。创建阶段只授权新 handler，页面/已有 handler 修复仍由原全量终验调用完成。对照取 0；本隔离默认候选取 1，ARC_FULL_CONTEXT=1 仍可强制原全量路径；所有 typecheck、浏览器回归、外部固定验收和构建保留。

风险是缺少页面源码后模型对接线的理解变差，可能把成本转移到终验修复。验收要求同一老师输入/固定验收下对照 token、调用、失败与重试，配合相同已录请求的上下文字符重放；不得把字符当 token 或单次不同生成轨迹当因果效应。完整结果未取得前维持 proposed，默认不启用。

实测全新对照 1,066,909 token 且外部验收 14/14；全新候选 819,564 token，但外部验收仅 7/14，不能作为合格版本或宣称成本优化达成。共享相同前置 IR 的 Stage 12 候选输入降 62.0%，外部验收先 13/14 网络空闲超时、未修改代码/断言原样重跑 14/14。10 个匹配非终验创建输入均值从 23,760.6 降至 6,321.4（73.4%），支持局部上下文下降；测试生成与终验轨迹仍不同。

早期失败后保留了显式试验开关，取 0；不修改稳定标签。下一轮先验证精确标签与会话故障语义，保持固定验收，并重复无人工修复的完整生成。结果及全部失败见 docs/experiments/event-context-comparison.json，不把失败候选的低 token 写成成功收益。


隔离的默认候选分支将对应开关默认设为 1，用于无开关的新目录验证；尚未晋升主线。只有原断言、全部阶段与固定验收通过后才合并，显式设置 0 仍可回退。
