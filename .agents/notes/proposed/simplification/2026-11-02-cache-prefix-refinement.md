# Agent Note: 进一步将共享需求和绑定置于事件变化之前

Status: proposed

ARC_CACHE_PREFIX_V2=1 在既有前缀排序开启时，将 Stage11 的 all_requirement_uses/backend_apis 置于当前事件之前，将收窄创建请求的 page_inventory/frontend_data/page_paths 置于源元素和事件之前。默认关闭；V2=0 回退现有排序，ARC_CACHE_PREFIX=0 则关闭全部排序。只移动字段，信息内容、指令、文件权限和全部 gate 不变。

历史默认运行离线重排的 Stage11 共同前缀字符累计115,381→255,413，Stage12为535,491→593,155；这些是最长历史匹配的字符数，不是token、服务器缓存单元或实测收益。目标是在不增加填充/无用上下文的前提下改进可复用输入。共享需求未必对全部事件相同，API集合也会变化，不能保证达到50%全流程命中。
