# Agent Note: 保留全部信息的稳定前缀调序

Status: proposed

ARC_CACHE_PREFIX=1 将 Stage 11 契约请求中共享的 frontend_data/page_inventory 前置，并把文件请求中的稳定 ui-runtime/ui-api 放在页面和动态 ui-events 注册表之前。所有字段、文件内容、写权限、gate 和终验上下文保留，对照开关为 0，本隔离默认候选为 1；不是删除上下文的 ARC_EVENT_CONTEXT 试验。

理由是相同文件顺序仍可能被靠前的页面改动截断，逐事件请求中的事件 ID 又位于共享上下文之前。调序的确定性验收为 JSON 值/字段和编辑权限完全一致，以及页面改动时更长的共同前缀；真实性能验收需要相同输入和固定验收的成功运行，比较 SDK cache hit/miss、总 token、耗时与修复次数，不能只报告字符前缀变长。

需保留无调序对照与全流程候选的原始计时/模型日志。仅单次随机轨迹变好不证明因果，服务端缓存是 best-effort；缓存收益应再用相同请求材料的受控回放核验。完整候选未通过以前不晋升默认。0 为显式回退，历史失败候选和已有稳定标签不动。结果只记录于本轮 work 实验，不重建交接材料。


隔离的默认候选分支将对应开关默认设为 1，用于无开关的新目录验证；尚未晋升主线。只有原断言、全部阶段与固定验收通过后才合并，显式设置 0 仍可回退。
