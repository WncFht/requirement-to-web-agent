# Agent Note: 保留结构化修复反馈

Status: proposed

OPT-F 的浏览器失败报告包含计数、错误列表和这些字段的 JSON 副本。旧 gate 将整个报告转成 Python repr，模型收到重复内容、字面转义后的 ANSI 和不易阅读的位置。只做字符串截断会丢失尾部诊断，不能解决重复来源。

首次传入的检查报告是字典，旧循环却按可迭代对象展开，模型只收到字段名；现在把完整字典作为一条初始反馈。实现以 `ValueError` 子类携带原始检查报告，在模型编辑循环中按结构传输；只有 `output` 解码后与其他全部字段相等才删除副本，其他输出保留。gate 判定、测试和原始审计日志均不改变。`ARC_FULL_FEEDBACK=1` 恢复旧反馈格式。

原始错误字符串仍用于终端诊断，代价是新增异常类型和更改模型可见的反馈形状。对空套件、失败断言、独有输出、源对象不变性及回退开关的测试已通过；17 份历史反馈的重放减少 60.8% 序列化字符，不能据此宣称总 token 或成功率改善。

验收要求是保留所有既有 gate、历史重放及单元测试通过，并完成一次隔离输出目录的全流程 GREEN。详细证据归 [实验报告](../../../../docs/experiments/2026-11-01-baseline-optimization.md)；全流程未完成前保持 proposed。
