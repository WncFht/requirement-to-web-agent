# Agent Note: 固定老师输入与独立验收

Status: proposed

当前只靠每次模型生成的测试，无法比较不同运行的完成程度，也曾把不合法的 fixture 注入接受为行为 RED。默认输入恢复为教师 ZIP 的原始字节，pending 扩展独立放到 examples/registration-pending；input/source.json 登记原始文件哈希。教师附带测试保持原字节，不按旧编号改写场景。

新增独立验收运行器，在隔离数据库/服务器上执行教师四条原始测试，并以固定浏览器/数据库断言覆盖首页读写边界、注册登录持久化、失败无写入、密码存储与失败不残留身份。适配器只负责由 schema 准备 Given 数据，不调用业务 API 代替预置；识别失败必须报错，不能静默跳过。验收属于额外 gate，不替换或放松现有阶段 gate。

验收内容、源码与输入身份固定在生成前。当前分阶段 CLI 行为保持，独立脚本在 main 完成后执行；稳定标签要求现有阶段、生产构建与独立验收全部通过。跨层问题不能靠修改冻结测试转绿；语义修正须另外记录并有回退路径。

Status 保持 proposed，直到完成真实组合验证，包含反例可拒绝、老师原文件校验与一次完整运行。视觉相似度另行人工检查，不把元素存在性当像素复刻保证。
